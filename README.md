# 🎬 Movie Recommendation System

An interactive and user-friendly **Movie Recommendation System** that recommends movies based on the user's preferences such as genre, language, mood, and rating.

The project is designed to provide a personalized movie-discovery experience through an attractive web interface.

## ✨ Features

- 🎬 Personalized movie recommendations
- 🎭 Multiple genre selection
- 🌎 Language preference
- ⭐ Minimum rating selection
- 😊 Mood-based recommendations
- 🔎 Movie search
- ❤️ Favorite movies
- 📊 Personalized match percentage
- 🖼️ Interactive movie cards
- 📱 Responsive design
- 🍿 User-friendly interface
- 🔄 Dynamic recommendations

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Machine Learning / Recommendation

The project can be extended using:

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Flask
